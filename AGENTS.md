# DistApp — Agent Instructions

## Project Overview
DistApp is a self-hostable app distribution platform for Android, iOS, and Desktop apps (alternative to App Center). Built with **Nuxt 3**, **Vue 3**, **TypeScript**, **TailwindCSS**, **PrimeVue**, **Drizzle ORM** (SQLite/Turso), and **Bun** runtime.

## Key Commands
```bash
# Development
bun install              # Install dependencies
bun run dev              # Start dev server (HOST=localhost HOST=0.0.0.0)

# Build & Preview
bun run build            # Production build (Cloudflare Pages preset)
bun run preview          # Preview production build
bun run generate         # Static site generation

# Code Quality (run in order)
bun run lint             # ESLint check
bun run lint:fix         # ESLint auto-fix
bun run format:check     # Prettier check
bun run format           # Prettier write

# Database
bun run drizzle:generate # Generate migrations from schema
bun run drizzle:migrate  # Run migrations (bun run server/db/migrate.ts)

# Testing
bun run tests -- --watch=false  # Unit tests (Vitest, dir: ./tests)
bun run e2e             # E2E tests (Playwright, dir: ./tests-e2e)
bun run e2e-ui          # Playwright UI mode

# Deployment
bun run deploy           # Build + Wrangler deploy to Cloudflare Pages

# CLI Tool (separate package in ./cli)
bun run build-cli        # Bundle CLI to cli/cli.mjs
bun run cli:pack         # Build + pack CLI for npm
bun run cli:publish      # Publish CLI to npm

# Documentation
bun run docs:dev         # VitePress dev server
bun run docs:build       # Build docs
```

## Environment Setup
**Required `.env`** (copy from `public/docker/docker-compose-base.env` and `public/docker/docker-compose.env`):
- `NUXT_DB_URL`, `NUXT_DB_AUTH_TOKEN` — Turso/SQLite database
- `NUXT_S3_ENDPOINT`, `NUXT_S3_ACCESS_KEY_ID`, `NUXT_S3_SECRET_ACCESS_KEY` — S3-compatible storage (MinIO, R2, SeaweedFS)
- `NUXT_JWT_KEY`, `NUXT_APP_CONFIG_API_AUTH_KEY` — Auth secrets
- `NUXT_CLERK_SECRET_KEY`, `NUXT_PUBLIC_CLERK_PUBLISHABLE_KEY` — Clerk auth (optional)
- `NUXT_PUBLIC_GOOGLE_CLIENT_ID` — Google OAuth (optional)
- `NUXT_LOCAL_AUTHS`, `NUXT_PUBLIC_LOCAL_AUTH_ENABLED` — Local auth (optional)
- `NUXT_BUNDLEAAB_*` — Android AAB signing keystore (optional)

**Test environment** (`.env.test`): Uses local SeaweedFS + sqld (SQLite HTTP). See `setup-test.sh`.

## Architecture & Entry Points

### Frontend (Nuxt 3)
- `app.vue` — Root component
- `pages/` — File-based routing (SSR on `/` and `/pricing` only; rest SPA)
- `components/` — Vue components (`.client.vue` = client-only)
- `layouts/` — `default.vue`, `auth-layout.vue`, `content-layout.vue`, `install-layout.vue`
- `composables/` — Shared Vue composables (`useAppDrawer`, `useAccount`, etc.)
- `middleware/auth-route-middleware.global.ts` — Client-side auth guard

### Backend (Nitro / server/)
- `server/api/**/*.ts` — API endpoints (auto-routed)
- `server/db/schema.ts` — Drizzle schema (single source of truth)
- `server/db/migrate.ts` — Migration runner
- `server/utils/drizzle.ts` — Drizzle instance + table exports
- `server/middleware/auth-middleware.ts` — Server auth middleware
- `server/plugins/startup.ts` — App initialization
- `server/tasks/*.ts` — Scheduled tasks (purge artifacts, purge uploads)
- `nitro: { preset: 'cloudflare-pages', experimental: { tasks: true } }`

### Database (Drizzle + SQLite/Turso)
- Schema: `server/db/schema.ts` (users, organizations, apps, artifacts, groups, apiKeys, subscriptions)
- Migrations output: `server/db/drizzle/` (copied to build output via nitro hook)
- Dialect: `turso` (libSQL HTTP)

### CLI Tool (`cli/`)
- Source: `cli/cli.ts` (commander.js)
- Command: `cli/commands/distribute.ts` — Upload artifacts to DistApp
- Built to `cli/cli.mjs` via `bun build`

## Testing Quirks
- **Unit tests**: `tests/` — Vitest with Nuxt environment (`@nuxt/test-utils`). Run `bun run tests`.
- **E2E tests**: `tests-e2e/` — Playwright. Requires `setup-test.sh` (starts SeaweedFS + sqld, downloads test artifacts, builds app with `--preset=bun`).
- **Test artifacts**: Downloaded from GitHub Releases (`tests_artifacts.zip`) on first run.
- **Auth state**: Playwright uses `playwright/.auth/user.json` (generated by `auth.setup.mts`).

## Common Gotchas
1. **SSR only on `/` and `/pricing`** — All other pages are SPA (`routeRules` in `nuxt.config.ts`).
2. **Drizzle schema is the source of truth** — Run `drizzle:generate` after schema changes.
3. **Nitro preset is `cloudflare-pages`** — Local dev uses Bun; production targets Cloudflare Pages.
4. **S3 signed URLs** — Artifacts downloaded/uploaded directly to S3; endpoint must be publicly accessible.
5. **Dark mode** — Tailwind `darkMode: ['variant', '&:where(.appdark, .appdark *)']`; toggled via `useAppTheme`.
6. **PrimeVue theme** — Custom `Noir` preset (extends Aura) in `nuxt.config.ts`.
7. **Scheduled tasks** — Defined in `nitro.scheduledTasks` (cron: `0 */24 * * *`).
8. **CLI is separate** — Must run `build-cli` before `cli:pack`/`cli:publish`.

## File Conventions
- API routes: `server/api/<resource>/<action>.<method>.ts` (e.g., `apps/create-app.post.ts`)
- Pages: `pages/<route>.vue` or `pages/<route>/index.vue`
- Components: PascalCase, `.client.vue` suffix for client-only
- Composables: `use<Name>.ts` (auto-imported)
- Utils: `server/utils/<name>.ts` (auto-imported via `imports.dirs`)

## Self-Hosting Quick Start
```bash
# One-liner install (interactive)
curl -fsSL https://distapp.app/install.sh | bash

# Manual: copy docker-compose*.env to .env, edit, then:
docker compose up -d
```
Requires: Docker, S3-compatible storage (publicly accessible), SSL termination.
